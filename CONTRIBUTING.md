\# How to Contribute



You don't need to know how to code to help with this project.



\## Ways to contribute (no coding required)

\- Review a map or notebook output and flag anything that looks wrong

\- Write up a short description of what a district's land change shows

\- Test a workflow and report if the instructions make sense

\- Fix typos or unclear wording in the docs

\- Suggest a new district or task to add



\## Ways to contribute (light coding)

\- Copy the template notebook and update it for a new district

\- Fix a small bug someone flagged in an issue



\## How the workflow works

1\. Pick a task from the Project board

2\. Do the work

3\. Submit it (ask a lead if you're not sure how)

4\. A reviewer checks it

5\. It gets merged in — done!

\- Suggest translations or simpler wording for non-native English speakers
